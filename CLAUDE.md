# Repo rules

## 1. NOTHING IS STATIC

NOTHING in this project is static or unchangeable. Even templates, once put into action, must be editable - every piece of them.

This applies to every page, board, view, template, and component in this repo: if it renders, it can be edited. Never ship anything whose content, structure, or styling is locked. When you build or change something, check it against this rule before you commit.
